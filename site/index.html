QUICK START

Install librtmp2

Use the official repository for your system. Commands below assume a supported release.

Ubuntu 26.04 · APT

Install with apt

curl -fsSL https://packages.openrtmp.org/openrtmp.gpg \
  | sudo tee /usr/share/keyrings/openrtmp.gpg >/dev/null

echo "deb [signed-by=/usr/share/keyrings/openrtmp.gpg] https://packages.openrtmp.org/ubuntu resolute main" \
  | sudo tee /etc/apt/sources.list.d/openrtmp.list

sudo apt update
sudo apt install librtmp2 librtmp2-dev
Select your distribution codename instead of resolute when using another supported release. Do not install a repository for a different distribution.
OTHER PLATFORMS
Debian APT

Follow the Ubuntu steps, but use https://packages.openrtmp.org/debian and trixie (Debian 13) or bookworm (Debian 12).

Alpine Linux APK
wget -O /etc/apk/keys/openrtmp-alpine.rsa.pub \
  https://packages.openrtmp.org/openrtmp-alpine.rsa.pub
echo "https://packages.openrtmp.org/alpine/v3.24/main" \
  >> /etc/apk/repositories
apk update && apk add librtmp2 librtmp2-dev
Fedora DNF
sudo tee /etc/yum.repos.d/openrtmp.repo >/dev/null <<'EOF'
[openrtmp]
name=OpenRTMP
baseurl=https://packages.openrtmp.org/rpm/fedora/44/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.openrtmp.org/openrtmp.asc
EOF
sudo dnf install librtmp2 librtmp2-devel
Arch Linux pacman

Import and locally trust the package signing key, then add https://packages.openrtmp.org/arch/$arch under [openrtmp] in /etc/pacman.conf. Full signed setup ↗

Homebrew macOS
brew install openrtmp/tap/librtmp2
Windows ZIP

Download an architecture-matched signed archive and checksum from the Windows repository. Verification instructions ↗

Enterprise Linux / openSUSE RPM

Repositories for Enterprise Linux and openSUSE are provided under rpm/. Use the matching DNF or Zypper setup in the documentation ↗.
